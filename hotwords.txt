# ==========================================
# 热词纠错文件 (hotwords.txt)
# ==========================================
# 使用音素 RAG 匹配，支持中英文混合。
# 具备强制性：相似度高于阈值的一定会被替换。
# 井号开头的行为注释，会被忽略。
# 每行一个热词，可以用 | 分割添加多个别名。
# 可以在热词与别名后，使用 ~~~ 分开添加"黑名单"防误杀词汇（也用 | 分隔）。
# 示例：傅平 ~~~ 工作 | 精准 | 脱贫
#   （当拟替换区间左右邻近一定语义词数内出现黑名单词语时，拦截不替换）
#
# 阈值由 .env 中 HOTWORD_THRESHOLD 控制（默认 0.85，越高越严格）。
# 关闭纠错可设 HOTWORD_ENABLED=false。
